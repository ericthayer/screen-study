ScreenStudy

Project Overview

ScreenStudy turns weekly work capture into a structured case-study draft and a review-gated publishing flow.

Current MVP Flow

  1. Capture weekly evidence quickly.
  2. Group entries by week.
  3. Generate a draft (problem, decisions, outcomes, impact).
  4. Flag low-confidence evidence gaps.
  5. Require explicit human review approval.
  6. Export markdown and optionally create a GitHub PR.

Stack

  • React 19
  • TypeScript
  • Vite 8
  • Vanilla CSS

Important: Use nvm use 24 before local commands.

Key Commands

  • npm run dev
  • npm run typecheck
  • npm run lint
  • npm run build
